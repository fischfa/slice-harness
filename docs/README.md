# Documentation map

- [Project profile](project-profile.md): initialized technology, boundaries,
  conventions, focused commands, and final verification gate.
- [Features](features/README.md): one document per bounded slice, with an index
  and template.
- [Harness](guide/harness.md): transitions, human control, consultation, and stop
  conditions.
- [Review](guide/review.md): neutral handoff and independent proof assessment.
- [Consultation](guide/consultation.md): optional bounded read-only advice packet.
- [Verification](guide/verification.md): project-neutral principles and required
  command mapping.
- [Contracts](../contracts/README.md): canonical public boundaries and evidence.
- [ADRs](adr/README.md): durable decisions and their index.
- [Client entry](guide/codex.md), [Claude prompts](../.claude/how-to-use-harness.md):
  invocation only, with no second backlog or client-specific engineering rules.

Open the relevant slice, decision, contract, and code on demand. Do not load every
completed record into a new session.
